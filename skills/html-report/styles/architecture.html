Architecture style: use archify

How to make a system diagram that matches the rest of this style set.

Do not hand-write architecture diagrams. Write a typed JSON file and let archify render it. Use the classic preset, dark theme by default. Keep the JSON next to the HTML so the diagram can be changed and re-rendered.

Why a tool, not a template

Archify validates the layout, routes, and labels before it writes the page. It also gives every diagram the same viewer: search, upstream and downstream tracing, light and dark themes, and PNG or SVG export. A hand-written diagram has none of this, and drifts from the JSON once someone edits it by hand.

Which diagram type

TypeUse it for
architectureComponents, services, storage, trust boundaries.
workflowLane-based steps: CI, approvals, tool calls, runbooks.
sequenceCalls in time order: API calls, auth, async traces.
data-flowPipelines, lineage, privacy boundaries, consumers.
lifecycleStates, retries, waits, terminal outcomes.

A boundary between two owners with allowed and never rules is a concept page, not an architecture diagram. Use concept.html for that.

House settings

  • Preset: classic. Theme: dark by default; the viewer toggles light.
  • Files: <name>.architecture.json (the source) and <name>.html (the render), side by side.
  • Views: add named views in meta.views, one per question a reader asks ("main path", "security model"), each with a one-line note.
  • Labels: plain words, write-plain rules. No internal code names in labels a public reader sees.
  • Evidence: where a node maps to code, use archify's source evidence mode to link the file at a pinned commit.

Steps

Install archify before the first run. It is an agent skill: npx skills add tt-a1i/archify -g.
  1. Ask the agent for the diagram type and the components, citing the code or records it reads.
  2. Have the agent write the JSON, then validate and deliver it with archify. Validation must pass before the HTML is replaced.
  3. Open the HTML. Check each view in both themes.
  4. Commit the JSON and the HTML together.
